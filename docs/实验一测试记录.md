两次运行均未出现 `WARNING: DATA RACE`，说明 Coordinator 中的共享状态访问和 Worker 的并发执行未触发数据竞争。

## 3. 任务状态机与迟到报告定向验证

官方测试没有单独覆盖“超时后旧 Worker 才回报”的状态变化，因此增加了一个临时内部测试（验证后已删除，不修改官方测试文件）。测试步骤与结果：

1. 第一次分配 Map 0，得到 `Attempt=1`；
2. 将任务开始时间人为回拨到 10 秒以前，再次请求任务，确认 Map 0 被重新分配为 `Attempt=2`；
3. 用 `Attempt=1` 发送成功报告，确认 `Accepted=false`，任务仍保持运行状态；
4. 用 `Attempt=2` 发送成功报告，确认被接受并标记完成；
5. 完成剩余 Map 和全部 Reduce 任务，确认阶段正确推进到 `phaseDone`，`Done()` 返回 `true`。

结果：PASS。日志见 [2026-10-27-stale-report-test.log](logs/2026-10-27-stale-report-test.log)。
